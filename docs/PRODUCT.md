# Producto

## Objetivo
Aplicación para control de viajes, pasajeros, asientos, reservas y saldos, utilizada por personas adultas con poca familiaridad tecnológica.

## Características clave
- Gestión de viajes
- Asignación visual de asientos
- Registro de abonos por reserva (no por asiento)
- Cuentas globales del viaje
- Offline first
- NO procesa pagos reales (solo registra)
